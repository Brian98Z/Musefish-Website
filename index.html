快速开始

三种方式任选，全程约 15–20 分钟（含模型下载）。

① 下载客户端（推荐）

从 GitHub Releases 下载 MusefishStudio-Client-*-win-x64.exe，免安装 portable，用 SHA256SUMS.txt 校验完整性。

② 一键准备环境

客户端内「设置 → 环境」点击两个按钮，或命令行：
python tools\env_setup.py
python tools\download_models.py
自动完成 venv + ComfyUI 内核 + 依赖 + 模型。

③ 启动工作台

运行 start_server.bat（或直接打开客户端），浏览器访问 http://127.0.0.1:17998 即可使用全部功能。

常见问题

部署形态、硬件要求与合规边界。

需要什么硬件？
NVIDIA RTX 50 系显卡（DLSS5 需要 NGX/D3D12 支持）；PiD / UniverSR / Mastering / ASR 在其他 NVIDIA 卡上也可运行，显存需求视模型而定。
数据会上传到云端吗？
不会。推理由本机 headless ComfyUI 引擎（:17996）完成，上传的媒体文件只经过本地工作台服务（:17998）暂存；仅模型下载与更新检查访问外网。
和 ComfyUI 插件是什么关系？
Musefish Studio 是 ComfyUI-Musefish-Nodes 插件的本地客户端：算法代码零复制，参数与插件源码逐字对齐；也可在设置里连接本机已装的任意 ComfyUI。
